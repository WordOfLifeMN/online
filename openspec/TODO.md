## Today (2026-10-17)

These three move the speaker from the title into the description. They go together and are best done as one small change.

**Going forward only.** The description rules (items 1 and 3) apply only to summaries generated from now on. Nothing checks, flags or changes an existing description, in the sheet or on YouTube. `sync` keeps using the sheet's `Description` column as it is, even when it's longer than 65 words or doesn't name the speaker. Bringing old descriptions up to the rules is a separate, later item: see "Backfill existing descriptions" below.

- [x] **Limit generated descriptions to 65 words.** The new website uses a bigger font, and a description should fill about half a mobile screen. Today's summaries run about 100 words: the prompt asks for "3 sentences in a casual voice", with no length cap (`cmd/audio_summarize.go`, `buildSummaryPrompt` and `summarySchema`). Put the 65-word limit in both places. **Drop "3 sentences"**: it's left over from before, so the summary is however many sentences suit about 65 words. *Done 2026-10-17:* a reply that's over 65 words, or doesn't name a speaker in full, is sent back once with what's wrong. If the corrected reply still breaks a rule, it's kept, and the message box shows a "Summary check" section listing the problems, so it can be edited before pasting. A 65-word example, for reference: "Pastor Mary Peltz challenges us to pay attention to God's voice and let Him question everything we think we know. Using Abraham's journey to Moriah, she shows how growth that stretches us leads to a clear, God-given destiny we then surrender to Him. In finances, relationships, and purpose, she calls us to partner with God, planting faith and calling forth the harvest."
- [x] **Remove speaker names from message titles.** The title becomes `[CORE | ]<title> | <date>`. This is a change to `FormatTitle` in `ytpkg/format.go` only. `stripSpeakerTitle`, `getTitleSpeakers` and their tests may then be removable. **Watch out:** every live video was titled with its speaker, including the 47 CORE videos retitled on 2026-10-12. `sync` will propose a title change for every video it touches. Decide whether that's wanted, as a bulk retitle, before running `sync` widely.
- [x] **Make sure speaker names are in descriptions, by enforcing it in the prompt.** Require the summary to name the speaker or speakers. **The first reference to each speaker uses the full name with the honorific**: "Pastor Vern Peltz", as `SpeakerString` gives it, never "Vern Peltz" or "Pastor Vern". **Later references may be shorter**, such as "Pastor Vern", "Vern" or "he". Honorifics were only ever dropped to save title length, and descriptions don't have that constraint. Check the reply contains each full name, honorific included, at least once before accepting it. Checking that the full form is the first mention isn't worth enforcing. This takes over the "moving speaker names into descriptions" idea in the formats item below.
